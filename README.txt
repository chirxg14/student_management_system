Student Management System (ASP.NET Core MVC, C#, EF Core + SQLite)

1. Install the .NET 8 SDK: https://dotnet.microsoft.com/download
2. Open a terminal in this folder (where StudentMgmt.csproj is)
3. If you ran an older version before, delete the file students.db first
4. Run:  dotnet run
5. Open the URL shown in the terminal (e.g. http://localhost:5000)

Default logins:
  Admin    -> admin / admin123    (students, users, attendance, report)
  Teacher  -> teacher / teacher123 (attendance, report, Excel download)

Admin can add or delete users from the Users page.
